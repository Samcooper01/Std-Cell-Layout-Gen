Cell Schematics

One schematic per distinct topology (drive strength variants such as _1 … _16 share the same structure, only the transistor widths change, so they are not repeated). The primitives are drawn at transistor level so you can see the CMOS structure; compound and sequential cells are drawn at gate or block level. The last section gives the rules to read every remaining variant from its name.

how to read a CMOS gate

Static CMOS is two dual networks between the rails. A PMOS pull up network ties the output to VPWR; an NMOS pull down network ties it to VGND. Exactly one network conducts at a time, so the output is always the inverted logic function. Transistors in series = AND; in parallel = OR.

symbols

Inverters, NAND, NOR: the CMOS primitives

inv

Y = A'

The atom: one PMOS pulls Y high when A=0, one NMOS pulls Y low when A=1.

nand2

Y = (A·B)'

PMOS in parallel (OR), NMOS in series (AND) → output low only when A and B are both high.

nor2

Y = (A+B)'

The dual of NAND: PMOS in series, NMOS in parallel → output high only when A and B are both low.

a21oi (AOI21)

Y = ((A1·A2) + B1)'

AOI means AND, then OR, then Invert, done in one gate. The digits are the sizes of the AND groups: a21oi is one 2 input AND group (A1·A2) and one 1 input group (B1), the two OR'd together and then inverted, so Y = ((A1·A2) + B1)'. Static CMOS builds this whole compound function in a single stage (one pull up network, one pull down network), which is smaller and faster than wiring up separate AND, OR, and inverter cells. The family just varies the group pattern: a22oi is (2 AND) OR (2 AND), a31oi is (3 AND) OR (1), and so on.

o21ai (OAI21)

Y = ((A1+A2) · B1)'

OAI is the mirror image: OR, then AND, then Invert. Now the digits are the sizes of the OR groups: o21ai is one 2 input OR group (A1+A2) AND one 1 input group (B1), inverted, so Y = ((A1+A2)·B1)'. Same single stage CMOS trick as AOI, just with the ANDs and ORs swapped (the pull up and pull down networks are the AOI ones traded). AOI and OAI together are the two largest families in the library, because so many logic functions collapse neatly into one of these compound gates.

Derived, transmission gate, and tristate cells

and2 · or2 · buf

AND = NAND then INV

and2 is a 2 input AND (output high only when both inputs are high), or2 is OR (high when either is high), and buf just copies its input with more drive. Because static CMOS is naturally inverting, each is the inverting gate followed by an inverter: and2 = nand2 then INV, or2 = nor2 then INV, buf = two inverters. That extra stage is why they are slightly slower than the raw NAND or NOR.

xor2 (transistors)

Y = A ⊕ B = A ? B' : B

Exclusive OR: the output is high only when the two inputs differ. The neat part is that XOR is really a 2:1 mux, pass B' when A=1 else pass B, which equals A⊕B. It is two transmission gates (each one NMOS and one PMOS) plus inverters for A' and B', so it packs more transistors than a plain 2 input gate. xnor2 is the same with the output inverted (high when the inputs match).

mux2 (transistors)

Y = S ? A1 : A0

A 2:1 multiplexer: it routes one of two inputs to the output, chosen by the select S. When S=0 it passes A0, when S=1 it passes A1. Each path is a transmission gate (one NMOS and one PMOS) that either connects its input straight to Y or shuts off. mux4 is a 4:1 version (a small tree of these), and mux2i inverts the output.

einvn (tristate, transistors)

Y = TE ? A' : Z (high impedance)

A tristate inverter: an inverter whose output can also be switched off entirely. It is a normal inverter with an extra series enable transistor in each arm. When TE is on it inverts A as usual; when TE is off both arms are cut, so Y floats at high impedance (Z) instead of driving a value. That lets several drivers share one wire (a bus) as long as only one is enabled at a time. einvp is the active high variant, ebufn is the buffer version.

Sequential: flip flop, scan, enable

dfxtp (D flip flop)

Q captures D on the rising CLK edge

A D flip flop: it samples D on the rising clock edge and holds that value on Q until the next edge. This is the basic memory element of synchronous logic, one bit of a register. It is two latches back to back on opposite clock phases, so Q changes only once per clock cycle rather than every time D moves.

latch (dlxtp, one latch at transistor level)

Q follows D while CLK is high, then holds while CLK is low

A level sensitive latch: while CLK is high it is transparent (Q follows D), and when CLK goes low it freezes and holds the last value. It is the atom of a flip flop: two inverters store the bit and two transmission gates switch between "follow" and "hold". A flip flop is two of these on opposite clock phases, which is exactly what makes it edge triggered instead of level sensitive.

s prefix (scan, for test)

sdfxtp: adds SCD, SCE

Scan is a test feature, not part of the logic. It adds a mux on D so the flop can take a special scan input SCD instead of the normal data, selected by scan enable SCE. In test mode every scan flop links up (each Q feeds the next SCD) into one long shift register, so a tester shifts a known pattern into all the flops, pulses the clock once, then shifts the results out. That makes the chip's internal state controllable and observable, which is how manufacturing test finds faults.

e prefix (enable)

edfxtp: adds DE

Enable lets the flop update only when you want it to. It adds a data enable DE and a mux: when DE=1 the flop loads new data D; when DE=0 the mux feeds Q back in, so the flop captures its own value again and nothing changes. The clock keeps ticking either way, so this is a safe way to hold a register bit without stopping the clock. Unlike scan, it is a real functional feature (a conditional load).

Wider basic gates

nand3

Y = (A·B·C)'

A 3 input NAND: output is low only when all three inputs are high. Same shape as nand2, just one more transistor in each network: three NMOS in series (a wider AND) and three PMOS in parallel. nand4 adds a fourth of each. Series NMOS gets slower as the stack grows, which is why very wide gates are rare.

nor3

Y = (A+B+C)'

A 3 input NOR: output is high only when all three inputs are low. The dual of nand3: three PMOS in series and three NMOS in parallel. Now the slow stack is on the PMOS side, so NOR gates fan wider less gracefully than NAND.

More AOI and OAI shapes

Every one is built from its digits exactly like a21oi and o21ai above. The digits are the group sizes; read them and you can draw any of the ~40 shapes.

a22oi

Y = ((A1·A2) + (B1·B2))'

AOI22: two 2 input AND groups, OR'd, then inverted. Pull down network: A1·A2 (two NMOS in series) in parallel with B1·B2 (another two in series). Pull up is the dual: (A1 ∥ A2) in series with (B1 ∥ B2). It is a21oi with the single input B1 grown into a second 2 input AND group.

a31oi

Y = ((A1·A2·A3) + B1)'

AOI31: one 3 input AND group, OR'd with a single input, inverted. Pull down: three NMOS in series (A1·A2·A3) in parallel with one NMOS (B1). Same as a21oi but the first AND group is three wide instead of two.

o22ai

Y = ((A1+A2) · (B1+B2))'

OAI22: two 2 input OR groups, AND'd, then inverted. The exact mirror of a22oi: pull down is (A1 ∥ A2) in series with (B1 ∥ B2), pull up is the two series pairs in parallel. The rest of the OAI family (o211ai, o32ai, o41ai, …) follows the same digit rule.

Arithmetic

ha (half adder)

SUM = A ⊕ B, COUT = A · B

Adds two bits. The sum bit is A XOR B; the carry out is A AND B. The smallest building block of arithmetic.

fa (full adder)

SUM = A ⊕ B ⊕ Cin, COUT = majority(A, B, Cin)

Adds three bits (two operands plus a carry in). The sum is a 3 input XOR (high when an odd number of inputs are high); the carry out is the majority (high when two or more inputs are high). Chaining full adders builds any width adder. fah, fahcin, fahcon are the same with the carry path split out for speed.

maj3

Y = A·B + B·C + A·C

Majority: output follows whatever value at least two of the three inputs hold. It is exactly the carry out of a full adder, and is built as a single compound (AOI style) gate rather than separate ANDs and ORs.

Tie, clock, delay, and physical cells

conb (tie cell)

HI = constant 1, LO = constant 0

Provides clean, buffered constant 1 and 0 outputs. You never tie an unused input straight to a rail (it hurts test and can stress the gate oxide); you drive it from a tie cell instead.

clock cells

clkinv, clkbuf, clkinvlp

Ordinary inverters and buffers, just sized and shaped for clock nets. Clocks drive huge loads and need balanced rise and fall, so these have tuned transistor ratios. clkinvlp is a low power (low leakage) version for always on clock branches.

delay cells

dlygate, dlymetal, clkdlybuf

Cells whose only job is to add a fixed, known delay. dlygate4sd* and clkdlybuf4s* are short chains of inverters or buffers; dlymetal6s* uses long metal routing. Used to fix hold time and tune clock skew.

fill, decap, tap, diode

no logic, physical only

These have no signal function; they satisfy manufacturing rules. decap is a capacitor across the rails that steadies the supply, tap is a well and substrate contact that pins the body voltage, fill just occupies empty space to keep density legal, and diode protects thin gates from charge damage during fabrication (antenna rule).

Low power and level shifting

lpflow level shifter (lsbuf_lh)

translate a signal from a low supply to a high supply

Two supply domains in one cell. A low voltage input can not fully turn off a high voltage PMOS, so you can not just feed it to a normal inverter. Instead the low side makes A and A', which pull down one of two cross coupled PMOS on the high supply; the cross coupling then snaps the output rail to rail on VDDH. The *isowell* variants add an isolated well so the domains can be powered down independently.

Reading every remaining variant from its name

and / or (and wider)

and2/3/4 and or2/3/4 are just the NAND or NOR of the same width followed by an inverter (CMOS is naturally inverting). Wider means more transistors in series and parallel, nothing new structurally.

b and bb variants

A b or bb in a gate name (nand2b, or4bb, and4bb) means one or two inputs are inverted first: add a small inverter on that input, then feed the normal gate.

xnor, xor3, xnor3

xnor2 is xor2 with the output inverted (high when inputs match). xor3 / xnor3 cascade two XOR stages (odd or even parity of three inputs).

mux4, mux2i

mux4 is a 4:1 mux, a small tree of the mux2 transmission gates with two select bits. mux2i is mux2 with an inverter on the output.

tristate variants

einvp is the tristate inverter with an active high enable, ebufn is the buffer (non inverting) tristate. Same series enable transistor idea as einvn.

reset / set / both flops

Suffix letters on a flop add an asynchronous force: r = reset (forces Q to 0), s = set (forces 1), bb = both. Physically it is the plain flip flop plus one transistor that yanks the internal latch to the known state regardless of the clock. Examples: dfrtp, dfstp, dfbbn.

latch variants

The dl* latches mirror the flop suffixes: dlrtp adds reset, dlxtn is the negative level version, dlclkp / sdlclkp are clock gating latches. All are the single latch above with the same tweaks.

scan + enable combos

sdf* is a scan flop, edf* an enable flop, and sedf* has both. They just stack the scan mux and the enable mux in front of the same flip flop drawn above.
