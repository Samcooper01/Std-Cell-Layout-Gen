# Documentation

Index of everything under `docs/`. Start with the top group to understand the generator; the
lower groups are reference material and running logs.

## Understand the generator
| Doc | What it covers |
|---|---|
| [TECH_FILE.md](TECH_FILE.md) | How `tech/sky130_hd_tech.py` works: the three layer split (process rules, library architecture, per cell recipe) and everything each layer holds. **Start here.** |
| [PNR_ENGINE.md](PNR_ENGINE.md) | How the place and route engine (lclayout) works: its inputs and outputs and every stage of the pipeline (netlist to placement to routing to LVS to output), with references into the actual code. |
| [CELL_TAXONOMY.md](CELL_TAXONOMY.md) | All 437 sky130 hd cells grouped into 16 functional categories, the naming convention, and a one line functional description of every cell. Generated by `src/cellgen/gen_cell_taxonomy.sh`. |
| [cell-schematics.html](cell-schematics.html) | Visual schematics, one per distinct topology: transistor level for the primitives, gate and block level for the rest. Open it locally in a browser. |

## Reference
| Doc | What it covers |
